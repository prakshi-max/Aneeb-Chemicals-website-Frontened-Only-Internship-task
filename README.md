# 🧪 Aneeb Chemicals – Modern Website Redesign

A modern, responsive, and premium redesign of the official Aneeb Chemicals website. This project focuses on improving user experience, visual aesthetics, performance, and accessibility while maintaining a professional corporate identity.

## 🌐 Overview

The goal of this project is to transform the existing Aneeb Chemicals website into a clean, modern, and user-friendly platform that effectively showcases the company's products, services, and brand.

## ✨ Features

- 🎨 Modern and professional UI/UX
- 📱 Fully responsive design
- ⚡ Fast loading and optimized performance
- 🌈 Clean color palette with premium styling
- 🧭 Smooth navigation and intuitive layout
- 📦 Product showcase section
- 🏢 Company overview and services
- 📞 Contact section with CTA
- ✨ Smooth animations using Framer Motion
- ♿ Accessibility-focused design

## 🛠️ Tech Stack

- **Next.js 15**
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide React Icons**

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/aneeb-chemicals.git
```

### Navigate to the project

```bash
cd aneeb-chemicals
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
